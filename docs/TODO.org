- Note taken on [2026-11-07 Sat 12:00:42+08:00] \\
  关于浮层和剪裁的关系，我认为并不是强相关的

  - 浮层本质是水印，测试的一些视频来自网络，会有视频制作者为了防止再分发
    而设置水印
  - 视频中某些水印的位置在视频画面的上半部分，因而剪裁后水印消失
  - 而某些在视频画面下半部分则 OCR 时会连带识别

  因而对于这样的问题，我认为可以两步走

  - 如果剪裁后水印消失，则表示去水印成功
  - 如果剪裁后水印仍在，则 OCR 识别完成后根据当前识别出来的文本上下文相
    关性来判断是否要去除
  - 这个过程我相信 llama-server 应该也有能力做
